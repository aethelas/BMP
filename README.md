BMP Reader на Flet

1) python -m pip install -r requirements.txt

## Запуск

python main.py


Приложение позволяет открывать BMP и другие поддерживаемые изображения, просматривать их размеры, пользоваться историей последних файлов и очищать просмотр. Отчёт о сеансе добавляется в `report.txt` при закрытии приложения.
